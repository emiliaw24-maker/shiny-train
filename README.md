# Agent Nauki

Prosty edukacyjny mini-projekt do nauki matematyki i polskiego.

## Co zawiera
- wybór przedmiotu: matematyka / polski
- pytania z odpowiedziami
- prosty licznik punktów
- responsywny interfejs web

## Jak uruchomić
1. Pobierz repozytorium.
2. Otwórz `index.html` w przeglądarce.

## Struktura
- `index.html` – główny układ aplikacji
- `style.css` – wygląd i responsywność
- `script.js` – logika pytań i punktacji

## Cel
Aplikacja ma działać jako prosty starter edukacyjny i może być dalej rozwijana o:
- więcej pytań
- poziomy trudności
- moduł logowania rodzica
- statystyki postępów
- backend i baza danych
